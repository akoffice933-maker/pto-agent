# Нормативная база агента

Каждая ссылка в акте сверяется с этим каталогом: есть ли документ, есть ли в нём пункт.
Три состояния, которые нельзя смешивать:

| статус | что значит |
|---|---|
| `verified` | документ и пункт есть в базе, документ загружен целиком |
| `verified_partial` | пункт есть, но документ загружен фрагментом (`status: fragment`) — цитату сверять по первоисточнику |
| `clause_missing` | документ есть, пункта нет (в ответе перечисляются пункты, которые есть) |
| `doc_missing` | документа нет — **ссылка не проверена**, а не «неверна» |

## Как добавить документ

Один файл `.md` на документ:

```markdown
---
designation: СП 76.13330.2016
title: Электротехнические устройства
kind: СП
edition: с Изменением № 1
status: active          # active | fragment
effective_from: 2017-01-01
version: 1
source: Минстрой России
---
# СП 76.13330.2016

## 6.1
Текст пункта дословно, как в документе.
```

Пункты — заголовки `## <номер>`, текст — тело пункта. Дословность важна: `asbuilt aosr`
проверяет цитаты через `cite_verify` и пересказ не подтверждает.
