# Harness: границы, инструменты, доказательства

Инструментов: 10 · уровни: auto — 4, confirm — 3, human — 2, never — 1 · запретов: 8

| Инструмент | Уровень | Что агент обязан предъявить | Почему так |
|---|---|---|---|
| сверка сметы и журнала | **auto** | по каждой строке: шифр, объём, цена, источник цены и версия выгрузки | пересчёт не меняет документы, ошибку видно сразу |
| акт КС-2 | **confirm** | источник каждой позиции; флаг «объём не подтверждён журналом»; пустые реквизиты — в запросы | печатная форма — черновик; подпись и УКЭП не в роли агента |
| цены ресурсов | **auto** | источник, дата действия, регион, версия выгрузки, digest — или отказ not_found | цена без даты и источника не используется |
| нормативный ответ | **auto** | дословная цитата и пункт; при отсутствии — «не найдено», а не пересказ | ответ без цитаты не выдаётся |
| проверка сметы по индексу | **auto** | ряд индексов, медиана, ряд демонтажа, список необъяснённых выбросов | не пересчитывает смету — только показывает отношение |
| объёмы по чертежу | **confirm** | страница/лист, единица, уверенность и что не распознано | распознавание ошибается; объём без подтверждения не идёт в акт |
| подпись документа | **human** | ФИО и роль человека из справочника пользователей | подпись — действие человека; агент только готовит |
| проводка в учёте | **confirm** | план проводок с основанием; фактическая проводка — только по команде человека | регистры ведутся всегда, проводки — по решению человека |
| отправка контрагенту | **never** | — | внешняя отправка — не действие агента ни в каком виде |
| изменение базы нормативов | **human** | источник (номер приказа/письма) и digest файла | нормативы меняются только решением человека, с указанием документа |

## Память агента

| Что помнит | Где | Как хранится |
|---|---|---|
| решения человека | `out/*/audit.jsonl` | весь журнал, с hash-цепочкой против удаления хвоста |
| версии цен | `data/prices_fsnb/index.json` | каждая выгрузка отдельным снимком, старая не перезаписывается |
| правила сопоставления | `data/reference/takeoff_map*.json` | в git, с указанием источника каждого кода |
| нормативы | `data/norms/*.md` | текст + пункт + редакция |
| результаты проверок | `out/eval/report.json` | последний прогон + baseline для сравнения с прошлым |

Сознательно не хранится:

- промежуточные объяснения LLM — не источник истины, не храним
- сырые сканы после разбора — остаются у пользователя, не в базе агента
