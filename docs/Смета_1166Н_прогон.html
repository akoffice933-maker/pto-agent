Найдено, что важно знать заказчику. В этой смете колонка «Прямые затраты» не включает стоимость материалов по норме, а колонка «Всего» включает. Поэтому «Всего» больше суммы ПЗ + НР + СП на 381 922,47 ₽ — это материалы, заложенные внутри расценок. Само по себе это не ошибка, но при сверке с актом КС-2 надо сравнивать именно колонку «Всего», иначе объём материалов потеряется.

4. Что осталось непроверенным — и почему

  1. Ставки НР и СП по нормативам. В PDF нет фонда оплаты труда по каждой норме, а НР и СП начисляются именно на него. Восстановленные от ПЗ 92,8 % и 48,6 % — не норматив, а следствие. Чтобы проверить по-настоящему, нужен либо файл АРОС в машиночитаемом виде, либо нормативы НР/СП по видам работ в базе.
  2. Объёмы работ против дефектной ведомости. Основание сметы — дефектная ведомость, её в комплекте нет. Без неё нельзя сказать, соответствует ли количество (например, 326,4 м кабеля 3×1,5) фактическому объёму.
  3. 25 шифров ГЭСН из 28. В базе знаний только ФЕР-2020; ГЭСН (в т.ч. ГЭСНр, ГЭСНм, ГЭСНп) не загружались, поэтому «не найдено» здесь означает «не с чем сверить», а не «ошибка в шифре».
  4. Индекс Минстроя к смете не применён. В документе указано письмо от 22.08.2025 № 49743-АЛ/09 (III кв. 2025). Проверить, что заложенные коэффициенты соответствуют этому письму, можно только по самим индексам для Ленинградской области — в разобранной базе индексов пока III квартал 2026, за 2025 год письма не скачаны.
  5. Оборудование 4 926,34 ₽ не разложено по позициям. В смете эта сумма есть в итогах по видам работ, но отдельными строками в разделах не выделена — сверить нечем.

5. Что сделать дальше

  1. Запросить у сметчика файл АРОС (или XML/Excel-выгрузку) — тогда проверятся ФОТ, НР, СП и нормативы по видам работ, а не только суммы.
  2. Запросить дефектную ведомость — сверить объёмы до подписания.
  3. Скачать письма Минстроя за III кв. 2025 (№ 49743-АЛ/09) и сверить восстановленные коэффициенты 1,12 / 1,22 / 1,08 / 1,20 / 1,16 / 0,94 с официальными индексами для Ленинградской области.
  4. При сверке КС-2 брать колонку «Всего», а не «Прямые затраты»: материалы 381 922,47 ₽ сидят внутри «Всего».
