# КС-2 за ноябрь 2026 по смете 1166/Н — отчёт о прогоне

Дата: 12.11.2026. Форма: КС-2 (Постановление Госкомстата России от 11.11.1999 № 100).
Объект: дошкольное отделение МОУ «Дубровская СОШ», ремонт электропроводки 2-го этажа.

## Что сделано

Собран акт КС-2 **только из сметы** — механизмом бланков, а не отдельным скриптом на стороне:

```
python3 scripts/check_smeta_pdf.py --pdf uploads/Смета_1166Н…pdf --out out/smeta_check
python3 scripts/ks2_from_smeta.py  --parsed out/smeta_check/smeta_parsed.json \
        --out out/ks2_from_smeta/lines.json --period 2026-11 --object "…"
python3 -m pto_agent forms ks2 --summary out/ks2_from_smeta/lines.json --period 2026-11 \
        --number 1 --vat-rate 20 --object-name "…" --out out/ks2_1166
```

Артефакты: `out/ks2_1166/ks2_2026_11_01.{docx,xlsx,md,json}`; экран — `docs/КС2_1166Н_акт.html`.

## Три дефекта инструмента, найденные прогоном (и исправленные)

1. **`TypeError` на шапке.** `build_ks2` передавал русские ключи реквизитов как именованные аргументы
   (`requisites() got an unexpected keyword argument 'Объект'`): акт падал, как только в шапке появлялось хоть одно значение.
   Теперь ключи идут словарём через `_req_map(...)`.
2. **Ставка НДС.** `--vat-rate 20` печаталось как «ставка НДС: 2000 %» — проценты и доля были смешаны.
   Добавлена нормализация `rate > 1 → rate / 100`, значение по умолчанию — 0,2.
3. **Период терялся.** Обязательный `--period` игнорировался: в `envelope` уходил `period_to`, `_month_label`
   его не узнавал, и файлы выходили с именем `ks2_без_периода`. Добавлена `_period_label_for(...)`,
   в `build_from_files` период подставляется в `payload["period"]`.
4. Бонусом: `scripts/ks2_from_smeta.py` формировал период как `2026-11-31` — несуществующая дата.
   Теперь последний день берётся из календаря (`month_bounds`), на это есть тест.

## Чего в акте нет (и почему)

- **Подтверждения выполнения.** Объёмы взяты из сметы, журнала работ и обмеров нет. Колонки «по журналу»
  и «к предъявлению» совпадают. Оговорка стоит в каждой строке.
- **Договора, Заказчика, Подрядчика.** В исходных данных их нет; поля не выдуманы, а вынесены в «требует данных»
  (лист XLSX и раздел на экране).
- **Проверки НР и СП.** Смета даёт их итогом; база начисления по каждой расценке не сверялась.
- **Пересчёта в текущие цены.** Цены — ФЕР-2020 (доп. 9) и ФСБЦ-2022 в редакции 01.01.2022; индексы Минстроя
  по Ленинградской области не применены. Суммы — в базисном уровне цен.
- **Подписи.** Черновик до УКЭП; юридической силы не имеет.
